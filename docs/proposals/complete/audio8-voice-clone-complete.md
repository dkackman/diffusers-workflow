# Audio8-TTS voice cloning for `generate_speech` (#1112)

Written by model `claude-opus-5-5` via provider `anthropic` (close-out,
2026-11-01). Plan v2 approved by Don on 2026-11-01 as "build smaller":
stage A (a listening gate, run outside dw) passed, then stages #1120 (B)
and #1121 (C) were built and verified. The plan comment on #1112 is the
full design; this doc records what shipped against it.

## The idea

Zero-shot voice cloning: a reference clip plus its exact transcript, then
new lines spoken in that voice, in many languages, from
[Edge0/Audio8-TTS-Realistic-0.6b](https://huggingface.co/Edge0/Audio8-TTS-Realistic-0.6b)
(Apache-2.0 with a NOTICE; a DualAR model with a bundled 44.1 kHz codec and
a 2,048-position context). Before this, the only varied-voice route was
SpeechT5 with a `speaker_embedding` clip, and there was no non-English TTS
voice. As shipped, the model ran only with `trust_remote_code=True` and
pinned `transformers<5`, so the route was to vendor and port it.

- **Q3:** one plugin line in `minimax-h3/references/dialogue.md`;

- **No `language` argument:** stage A generated Russian from the text

## What was built

### Stage B, #1120: the vendored model module

`dw/tasks/audio8_tts_model.py` (about 2,000 lines): the upstream config,
DualAR model, codec and processor at `1e857568`, ported to transformers
≥5.19. Header in the `rife_model.py` shape with the Apache-2.0 licence and
the upstream NOTICE; `docs/ATTRIBUTIONS.md` row. Inert on landing.

Deviations from the plan, none changing scope:
- **No transformers base classes at all.** A plain config class with
  `from_json_file`, plain-dict outputs, logits processors and stopping
  criteria as lists of callables. The model is built on meta and loaded
  with `load_state_dict(strict=True, assign=True)`; the state-dict keys and
  shapes were checked against the real checkpoint headers.
- **No Hub I/O, no torchaudio.** Local paths only; resampling and loading
  go through dw's own audio helpers. Upstream's `reference_codes` `np.load`
  input was dropped, and a reference given as a URL is refused.
- **Weight norm folded at load**, and the snake activation runs eagerly
  instead of under `torch.jit.script`.
- **Security sweep of the code as vendored:** no subprocess, `os.system`,
  `eval` or `exec` upstream; Hub fetches and the `trust_remote_code`
  passthrough were dropped.

Tests: `tests/test_audio8_tts_model.py`, 14 tests (a tiny model through
`generate` → `decode_audio` on CPU, logits matching the source, the
weight-norm fold, the codec frame grid, the processor, the `weights_only`
spy, and no Hub names in the module).

### Stage C, #1121: wiring, template, docs

- **Dispatch.** `generate_speech` has an explicit branch for
  `Edge0/Audio8-TTS-Realistic-0.6b` ahead of `pipeline("text-to-speech")`.
  The trust gate runs first, then the argument checks, then the load.
  Cache key `("speech_generation", repo, device, dtype, revision)`; output
  a 44.1 kHz mono `AudioTrack`.
- **Pinned weights.** `required_weights` returns `file_entries` at
  `1e857568` for `config.json`, `generation_config.json`,
  `model.safetensors`, `tokenizer.json` and `codec.pth`, each fetched with
  `hf_hub_download(revision=)`.
- **Arguments.** `reference_audio` and `reference_text` each need the other
  (an empty transcript counts as missing). Both are refused on any other
  model; `speaker_embedding`, `voice_preset` and `messages` are refused on
  Audio8. No reference means the default voice.
- **Length.** A reference over 20 s, and text estimated not to fit the
  context, are refused before the load, never truncated.
- **Catalog.** `workflows/templates/voice-clone.json` (shape `audio`,
  `has-audio` + `needs-input-media`, with the model card's consent note);
  `reference_audio` in `catalog_shape._MEDIA_ARGUMENTS`; one line in
  `generate-speech.json`'s description.
- **Docs.** `docs/TASKS.md` (Speech Generation row, both arguments, a
  "Cloning a voice" section), `docs/SECURITY.md` (the codec load and the
  remote-code argument refusal), and the plugin line in
  `minimax-h3/references/dialogue.md`.

Deviations from the plan, none changing scope:
- bf16 on CUDA, fp32 elsewhere.
- The fit check is an estimate from text length; a line that passes it but
  doesn't finish inside the context is refused after generation
  (`finished` false), never returned cut off.
- `max_new_tokens` defaults to the room left in the context (up to 2048),
  not the generation config's 512.
- `generate_kwargs` / `forward_params` on Audio8 are allowlisted:
  `temperature`, `top_p`, `top_k`, `do_sample`, `max_new_tokens`.
- The seed goes to `generate` through an explicit `torch.Generator`,
  because the codec's lazy construction consumed the global RNG and made
  the first take differ from later ones.
- `COMPACT_BUDGET` in `tests/test_catalog_structure.py` raised from 12,400
  to 12,480.

### Bounce fix (C): top-level Hub-code arguments

`generate_speech` now refuses `trust_remote_code`, `custom_pipeline` and
`custom_generate` given as top-level step arguments, for every model
(Audio8, Bark, SpeechT5, the default), before anything loads:
`UntrustedWorkflowError` when untrusted, a `ValueError` when trusted, a
falsy value allowed. Before, a kwargs task dropped them silently. No Hub
code loaded either way (the model is vendored and Bark/SpeechT5 never read
the key), but the step ran with no refusal and no warning.

## Not built, and why

- Streaming, SGLang serving, fine-tuning, other Audio8 checkpoints:
  non-goals.
- Bark stays the default `generate_speech` model and the H3 timbre
  template's default; `voice-clone` is named as an alternative.
- A Russian reference clip for Russian output (the English-reference
  Russian clones sit near ECAPA's same-speaker line): not probed, out of
  scope.

## Known edges

- **The template's `reference_audio` default is `asset:voice.wav`**, a
  placeholder that names no real asset. The variable is required, so a run
  without one is refused at validate (C-F597); a caller must supply a clip.
- **The remote-code argument refusals happen at run time**, not validate
  time, like the `forward_params` / `generate_kwargs` gate before them.
- **No job event names the pinned revision** when it loads; the pin is
  visible in the validate plan's `downloads_required`.
- **Transcribe with a large Whisper for `reference_text`.** The default
  `whisper-base` badly mis-transcribed the QA reference;
  `openai/whisper-large-v3-turbo` was close.
- **Port drift.** A future transformers bump touches little (no base
  classes are used), but the tiny-model test is the tripwire.
- Found during verify, filed and fixed separately: #1134 (`attribute_voices`
  refused a `previous_result:` voice reference).

## Reopen triggers

- Edge0 ships a transformers-5 release, or the architecture lands in
  transformers: the vendored module could shrink to a pin.
- A newer Audio8 revision: re-review the code before moving `REVISION`.
