# dw web UI: UX and bug review, 2026-11-22

Six reviewers worked in parallel. Each ran its own seeded fixture server and drove it in Chromium with Playwright. The jobs reviewer also ran real SD 1.5 jobs on MPS. No repo files were changed.

- [B] means confirmed in the browser. [S] means seen in the source only.
- Screenshots are under `scratchpad/ux-{shell,workflows,jobs,gallery,requests,crosscut}/shots/`.

## Tier 0: data loss, or "Saved" when nothing was saved

Fix these first. Most of them share one of two root causes.

### Root cause A: an edit is applied only when the field loses focus, but save runs without blurring it

1. **[B] Cmd+S in the JSON view saves the old document and says "Saved".**
   - Where: `editor/JsonEditor.svelte:68-71`, and `EditorPage` `onKeydown`.
   - Cmd+Enter (Run) and Validate have the same gap.
   - The "unsaved" chip never lights while there is an unapplied draft (`editorShell.svelte.ts:41`).
2. **[B] Cmd+S in the prompt editor saves the old text and says "Saved".**
   - Where: `PromptEditorPage.svelte:319`. The field uses `onchange`; it should use `oninput`.
3. **[B] Switching from the JSON view to the form view drops the edit silently.** This includes JSON that doesn't parse.
   - Where: `ed.setView()`.

**Fix:** give the editors one `flush()` that runs before save, run, validate and any view switch. Apply edits as you type (debounced), and count an unapplied draft as dirty.

### Root cause B: there is no check for overwriting, and no guard on leaving with unsaved edits

4. **[B] Save after a failed load overwrites the real file with the blank starter.**
   - Where: `EditorPage.svelte:176-184, 286-312`.
   - Any 500, timeout, missing token or unknown name triggers it. `PromptEditorPage` has the same pattern.
   - Fix: when the load fails, show an error panel with Retry, and disable Save, Run and Validate.
5. **[B] Saving a new workflow under an existing name replaces that file.**
   - Where: `EditorPage` `save()`.
6. **[B] Saving a new prompt under an existing name replaces it.**
   - Every `prompt:` reference to it changes silently (`PromptEditorPage.svelte:169`).
7. **[B] Uploading an asset under an existing name replaces it, with no prompt.**
   - Where: `dw/server/routes/assets.py` `upload_media`.
   - Fix: refuse unless `overwrite=true` is passed. Reuse the "Replace?" flow that Keep-as-asset already has.
8. **[B] Leaving with unsaved edits loses them.**
   - The sidebar, the Back button and the header breadcrumb all leave the editor without asking. Only the page's own breadcrumb links ask. The prompt editor has no guard at all.
   - Fix: a router-level dirty guard. Optionally autosave a draft to sessionStorage.
9. **[B] Two tabs saving the same workflow or prompt overwrite each other with no warning.**
   - Fix: send an etag or mtime with the save and return 409 on a mismatch, as request plans already do.
10. **[B] Bulk delete in the gallery removes starred files without mentioning them.**
    - "Select all matching (267)" followed by Delete takes the keepers with it.

## Tier 2: highest-value UX changes, grouped by theme

### A. Show what happened, and what to do next
- **Finished job page:** put Results (or an Error summary) first, and collapse Progress and the graph. Today results start around y≈600, and a failed job puts about 1,300 px of expanded traceback after everything else. Map known errors to a next step: OOM leads to Run with changes, "divisible by 8" leads to the size fields, a gated model leads to Models. *(jobs 2, 3)*
- **Run check:** lead with a one-line verdict and the remedy, and put the engine math behind "details". Give gated models their own verdict, "will fail: needs Hugging Face access", instead of "admitted, with warnings". *(workflows 8, 10)*
- **Seed warning:** it fires on nearly every template, and it is wrong. The workflow does set `seed: variable:seed`; the default is just null. Reword it for the person running the workflow, and give the template and the starter a default. *(workflows 9, jobs 13)*
- **Requests:** show why a take failed, inline. "Needs you" should count only items the user can act on. The Requests list should show every kind of item that needs the user (held, takes to choose, failed), not just the first. *(requests 2, 3, 4)*

### B. Make results findable and recognisable
- **Jobs list:** every row looks the same. Add a thumbnail, a prompt snippet, the note and a live percentage. Search by prompt, id and note. This is the "show the proof" rule in ui/CLAUDE.md. *(jobs 4)*
- **Gallery viewer:** the image tops out at 480 px. Add a real lightbox with zoom, fullscreen, previous/next buttons and swipe. Keep the active tile scrolled into view, and put the open file in the URL. *(gallery 7)*
- **What made this image:** prompt, seed and settings are in a collapsed section that closes again on every step. Show them open, with the full argument list, the image size and copy buttons. *(gallery 8)*
- **Gallery search:** match the prompt and note text, not just the path. Add a sort, date grouping and an "N of M" count. *(gallery 9)*
- **Catalog search:** "video of a cat" finds nothing among 133 workflows. Match every word against the name, description and traits, show "N of 133", and keep the filters in the URL. Cards should say what input each workflow needs ("needs: image, mask") rather than "1 vars". *(workflows 13, 14)*

### C. Make the creative's path easy
- **Run form:** give image, video and audio variables upload, browse and preview, and filter the suggestions by kind (today `output:` offers .txt files for an image). Remember the values last used. Split the form into Essentials and Advanced. Show a prompt preview, and add an Enhance button. *(workflows 11, 12, 21, 24)*
- **Run again with changes:** prefill the current values instead of showing them as placeholders. Add a "new seed" checkbox and send typed values. *(jobs 5)*
- **Reuse:** "keep" means two things today. Rename the star to "Star", and add "Copy `output:` reference" and "Use as input". Replace `window.prompt` with an in-app dialog. *(gallery 10)*
- **First run:** add a dismissible "what this is / pick → run → gallery" card on the Overview that links the ungated text-to-image template. Make the empty states buttons. The first cards are gated models a newcomer can't run. *(shell 6, 7)*

### D. Make the power user's path easy
- **Chaining:** media fields don't offer `previous_result:`, and in text fields it comes after about 30 `prompt:` entries. Offer the earlier steps first. Renaming a step should rewrite the references to it; today they break, and the step also collapses. *(workflows 6, 7)*
- **Validation errors:** clicking one should jump to its step or field. Re-validate on a debounce. Add undo for removing a step or variable. *(workflows 18, 23)*
- **Component slots:** list them from the pipeline's `__init__` instead of a static list. *(workflows 19)*
- **Variable names:** validate them inline, using the project's own pattern. Infer types (today 30 is stored as `"30"`), and let Enter add a variable. *(workflows 17)*
- **Read-only examples:** show a banner in the editor ("Save makes your own copy"). *(workflows 22)*

### E. Resilience and loading
- **Loading vs empty vs error:** keep these as three separate states. Today loading shows "No jobs yet", and an error sits above an empty state. *(crosscut 7, shell 2)*
- **Server status:**
  - Don't offer LAN URLs on a loopback bind. *(shell 3)*
  - Only blame the token for a 401. *(crosscut 6)*
  - Don't show the free-space warning when the quantized cache is disabled. *(shell 17)*
- **Remote performance:**
  - The server doesn't compress anything. Add `GZipMiddleware` and send `immutable` cache headers on `/assets/*`.
  - Add a tiny loading shell to `index.html`.
  - Import monaco's editor API with JSON only; the JSON view currently pulls 5.1 MB, which took 7.9 s at 5 Mbps.
  - Overview fetches 281 KB of workflows just for a count.
  - The Jobs page polls the entire job history every 3 s.

  *(crosscut 8, jobs 17)*

### F. Vocabulary
These come from the cross-cutting reviewer's glossary.
- **One run of a workflow has six names:** job, run, take, attempt, v1/v2 and "result (latest)". Use "job" for the record and "take" only inside a request.
- **A workflow has two names:** its file name (`e2e-card`) and its JSON id (`E2ECard`), which the Jobs list, toasts and the tab title show. Show the file name everywhere.
- **Accept, Star and Keep all sound like "I like this one"** but do three different things.
- **Hold text is jargon:** "No session is listening, so nothing will run at…".
- **Two messages contradict each other:** "Every image saves its recipe" against "no embedded metadata – enable embed_metadata".
- **A "~" in the monospace font reads as a minus sign:** "~3 min" looks like "-3 min".
- **Breadcrumb names don't match the sidebar:** it says `edit` and `prompt-edit`, the sidebar says "Editor" and "Prompts".

## Tier 3: smaller fixes (one line each)

**Shell**
- The Overview overflows sideways at 390 px, and one request title is squeezed to zero width.
- Switching workspace from the Overview requests the old workspace's thumbnails (404s).
- The collapsed sidebar can't switch workspaces.
- The new-workspace field has no buttons and doesn't close when you click away.
- The delete-workspace confirm reads "…removes these files permanently. / nothing", and its button isn't styled as dangerous.
- The Manage panel on `default` is all disabled controls.
- Overview tiles link to the whole gallery instead of the file.
- The header meter has no state word or label once the worker starts.

**Jobs**
- A queued row breaks the list grid.
- An empty agent-notes box appears on the job of a dropped request item.
- The workflow shown on the job page goes stale after the job finishes.
- The seed chip disappears after a server restart.
- Non-message event-log rows are raw JSON, and the log doesn't follow new events.
- The ETA is in raw seconds ("~1840s left").
- Cancel has no confirm and no error handling.

**Gallery and assets**
- Cancelling "Replace?" shows an error toast containing "pass overwrite=true".
- A failed metadata request is reported as "no embedded metadata".
- A video keeps keyboard focus after one click, so the arrow keys stop stepping.
- Dropped unsupported files are uploaded anyway.
- The Assets grid loads full originals instead of thumbnails.
- Compare has no empty state.
- Tiles are square crops.

**Requests**
- Mark done and Abandon happen in one click, with no confirm or undo.
- A closed request still shows the reorder and drop controls.
- Agent edits arrive with no visible cue, and renames aren't announced.
- "Plan changes" shows the agent's reason but not what changed.
- The run dialog shows raw engine text.
- Reordering allows an order that contradicts dependencies.

**Editor**
- After saving a new workflow the URL stays `/edit`.
- LoRA rows have no labels.

**Accessibility**
- There is no skip link; it takes 24 Tab presses to reach the main content.
- Route changes don't set the page title or move focus.
- The editor's view switch has no `aria-pressed`.
- Opening the drawer doesn't move focus into it.
- Every confirm dialog is named just "confirm".

**Other**
- A second `confirmDialog()` while one is open leaves the first caller waiting forever (`confirm.svelte.ts`).
- Back scrolls to the top instead of restoring your place.

## What wasn't tested
- CUDA and multi-card setups.
- A real out-of-memory error.
- Desktop notifications, which headless Chromium blocks.
- Model downloads and the diffusers update.
- Chained jobs with real data.
- The hold banner with an agent session listening.
- Real screen readers.
- Touch drag.
- Read-only example folders: the fixture's workflow directory is writable.
- Galleries with thousands of files.

## Suggested order
1. Tier 0, root cause A: one `flush()` in both editors. A small change that closes three bugs that report "Saved" when nothing was saved.
2. Tier 0, root cause B: overwrite checks for workflows, prompts and assets; a router dirty guard; no save after a failed load; etags.
3. Connection state: an offline/401 banner, the token taking effect immediately, pages recovering on their own, and the SSE `onerror` (11-14).
4. The quick cheap bugs: 15-18, 20, 22.
5. Then Tier 2 by theme. A and B give the most for a new user.
